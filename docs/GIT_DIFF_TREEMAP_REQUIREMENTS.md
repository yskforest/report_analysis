# Git 差分 Treemap 可視化 要求仕様書

## 1. 目的

本仕様書は、Git の特定タグまたはコミット ID を基準として、現在のコードとの差分を集計し、コード総行数と変更行数を Treemap で可視化するスクリプトの要求を定義する。

## 2. スコープ

### 2.1 対象

- Git リポジトリ内の追跡対象ファイルの収集
- 指定した基準リビジョンから比較先までの差分行数集計
- ファイル別のコード総行数、追加行数、削除行数、変更行数の CSV 出力
- コード総行数 Treemap と変更行数 Treemap の HTML 出力
- 出力先ディレクトリの自動作成

### 2.2 非対象

- Git 未追跡ファイルの差分集計
- バイナリファイルの行数集計
- 言語別の厳密な有効コード行数解析
- Git 履歴そのものの変更やタグ作成

## 3. 用語定義

- Base Ref: 比較元となるタグ名、ブランチ名、またはコミット ID。
- Target Ref: 比較先となるタグ名、ブランチ名、またはコミット ID。既定値は `HEAD`。
- Worktree: 現在の作業ツリー。オプション指定時のみ比較先として扱う。
- コード総行数: 比較先に存在する対象テキストファイルの総行数。
- 変更行数: Git diff の追加行数と削除行数の合計。

## 4. ユースケース

1. リリースタグから現在の `HEAD` までの変更規模を確認する。
2. 任意コミットから現在の作業ツリーまでの変更行数を確認する。
3. ディレクトリ階層ごとのコード量と変更量を Treemap で俯瞰する。
4. ファイル別 CSV を利用して、変更規模の大きいファイルを抽出する。

## 5. 機能要求

### 5.1 CLI 要求

- 実行形式は以下を満たすこと。

```bash
bash src/run_git_diff_treemap.sh {BASE_REF} {OUTPUT_DIR} [OPTIONS]
```

- `BASE_REF` にはタグ名またはコミット ID を指定できること。
- `OUTPUT_DIR` が未存在の場合は作成すること。
- 比較先は既定で `HEAD` とすること。
- `--target-ref` により比較先のタグ、コミット ID、ブランチを指定できること。
- `--worktree` により比較先を現在の作業ツリーに切り替えられること。
- `--repo` により対象 Git リポジトリを指定できること。
- `--git-dir` により対象 Git ディレクトリを指定できること。`--repo` と同義とすること。
- `--git-dir analysis_code/Open3D` のように、親プロジェクト配下の別 Git リポジトリを対象にできること。
- `--extensions` により集計対象拡張子を制御できること。
- `--exclude` により除外 glob を追加指定できること。
- `--treemap-max-depth` により Treemap の最大階層深さを指定できること。
- `--progress-interval` により進捗表示間隔を指定できること。
- `--no-progress` により進捗表示を無効化できること。

### 5.2 差分集計要求

- Git diff の `numstat` 相当情報を利用し、追加行数と削除行数を取得すること。
- 変更行数は `追加行数 + 削除行数` として算出すること。
- リネームされたファイルは比較先パスを代表パスとして扱うこと。
- バイナリ差分は行数集計対象外として扱うこと。
- 比較先が Git ref の場合、ファイルごとの Git プロセス起動を避け、Git blob を一括読み出しして行数集計できること。

### 5.3 コード総行数集計要求

- 比較先に存在する追跡対象ファイルを集計対象とすること。
- 既定では主要なソースコード・設定ファイル拡張子のみを対象とすること。
- `--extensions all` 指定時は拡張子で除外しないこと。
- NUL バイトを含むファイルはバイナリとみなし総行数を `0` とすること。

### 5.4 可視化要求

- 以下の HTML を出力すること。
  - `code_total_lines_treemap.html`: コード総行数を面積、変更率を色として表す Treemap
  - `changed_lines_count_treemap.html`: コード総行数を面積、変更行数を色として表す Treemap
  - `changed_lines_treemap.html`: 変更行数を面積として表す Treemap
- Treemap はディレクトリ階層とファイル階層を表現すること。
- 変更率と変更行数の両方を Treemap で確認できること。
- `index.html` から主要成果物へ遷移できること。
- 大規模リポジトリでは、指定階層で Treemap データを集約し、描画負荷を抑制できること。

### 5.5 進捗表示要求

- ファイル一覧取得、差分取得、行数カウント、CSV 出力、Treemap 出力の処理段階をログ表示すること。
- 行数カウント中は処理済みファイル数、総ファイル数、経過秒を表示すること。

### 5.6 CSV 出力要求

- `git_diff_file_metrics.csv` を出力すること。
- ファイル別 CSV は最低限以下の列を持つこと。
  - `File`
  - `TotalLines`
  - `AddedLines`
  - `DeletedLines`
  - `ChangedLines`
  - `ChangeRatio`
- `git_diff_summary.csv` を出力すること。
- サマリ CSV は比較元、比較先、対象ファイル数、変更ファイル数、総行数、追加行数、削除行数、変更行数を含むこと。

## 6. 入出力要求

### 6.1 入力

- Git リポジトリ
- 比較元のタグ名またはコミット ID
- 出力先ディレクトリ
- 任意の比較先 ref、拡張子フィルタ、除外 glob

### 6.2 出力

- `OUTPUT_DIR/git_diff_file_metrics.csv`
- `OUTPUT_DIR/git_diff_summary.csv`
- `OUTPUT_DIR/code_total_lines_treemap.html`
- `OUTPUT_DIR/changed_lines_treemap.html`
- `OUTPUT_DIR/index.html`

## 7. エラー処理要求

- 終了コード:
  - `0`: 正常終了
  - `1`: 異常終了
- 異常終了条件:
  - Git リポジトリではない
  - `BASE_REF` または `TARGET_REF` が解決できない
  - 出力先ディレクトリを作成できない
  - Git コマンド実行に失敗した

## 8. 非機能要求

- 冪等性: 同一入力・同一出力先で再実行可能であること。
- 保守性: Git 呼び出し、集計、可視化を関数単位で分離すること。
- 可観測性: 実行対象リポジトリ、比較元、比較先、主要出力先を標準出力に表示すること。
- 移植性: Python 標準ライブラリ、`pandas`、`plotly`、Git CLI で動作すること。

## 9. 受け入れ基準

1. タグまたはコミット ID を `BASE_REF` として指定して正常終了できること。
2. `git_diff_file_metrics.csv` にファイル別の総行数と変更行数が出力されること。
3. `git_diff_summary.csv` に全体サマリが出力されること。
4. コード総行数 Treemap と変更行数 Treemap が HTML として出力されること。
5. `--worktree` 指定時に現在の作業ツリーを比較先として扱えること。
6. 比較元または比較先 ref が不正な場合、終了コード `1` で異常理由を出力すること。
